# SaaS_Sales_Analytics
Data Modelling and Revenu analysis of SaaS Sales Data set using SQL and Power BI

## Overview

This project focuses on analyzing SaaS revenue trends and identify key drivers impacting revenue performance. A flat file data set was transformed into structured star schema using SQL. Data was further analyzed using SQL to find trends and drivers like discount, products and customer segments.Insights were visualized through Power BI to hightlight revenue trends and revenue drivers.

# Project Objective: To identify revenue trend, key revenue drivers and their impact on revenue

# Dataset: Sourced from Kaggle (10,000 records)

# Tools: SQL & Power BI
