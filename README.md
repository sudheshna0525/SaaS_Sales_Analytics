# SaaS_Sales_Analytics
Data Modelling and Revenu analysis of SaaS Sales Data set using SQL and Power BI

# Project Overview
This project analyzes SaaS revenue data to identify key drivers impacting revenue performance. A flat-file dataset was transformed into a structured star schema using SQL for analysis. The data was further analyzed to uncover revenue trends and key drivers such as discounts, product categories, and customer segments. Insights were visualized through an interactive Power BI dashboard to highlight revenue patterns, drivers, and potential risks.

## Project Context: 
Stakeholders aim to develop strategies to increase revenue, but first require a clear understanding of the factors driving revenue growth and those negatively impacting it. This analysis focuses on identifying revenue drivers, potential leakage points, and overlooked opportunities for growth. 

## Project Workflow
1. Data validation using SQL  
2. Data modeling into star schema  
3. Exploratory analysis to identify revenue trends and drivers  
4. Dashboard creation in Power BI  

## Dataset and Tools
- **Dataset**: Sourced from Kaggle (10,000 records)  
- **Tools**: SQL (data modeling and analysis), Power BI (visualization)

# Data Overview
This dataset contains transaction-level records of customer orders across multiple regions, countries, product categories, and business segments from 2020 to 2023

# Data Model
The dataset was transformed into a star schema consisting of a central fact table (sales) connected to dimension tables such as customers, products, geography, date to enable efficient querying and analysis.
